# Sistemas Operativos (2026/2027)

Repositorio de prácticas de Sistemas Operativos. Incluye ejercicios sobre
procesos, comunicación entre procesos, comunicaciones en red y concurrencia.

## Prácticas

| Práctica | Contenido | Documentación |
|---|---|---|
| Práctica 1 | Creación y coordinación de procesos, tuberías y memoria compartida. | [practica1/README.md](practica1/README.md) |
| Práctica 2 | Comunicación cliente-servidor con sockets y sincronización con semáforos. | [practica2/README.md](practica2/README.md) |

Cada práctica contiene sus fuentes y un README con una descripción de sus
ejercicios. Para compilar o ejecutar un programa, consulta las instrucciones de
la práctica o subcarpeta correspondiente: los requisitos dependen de la
herramienta utilizada (por ejemplo, `gcc` o JBACI).
